Complete TLE Computer Programming Study Guide

All 11 core topics covered in the 6 PowerPoint Presentations above

11 Topics Total
  • 1. Introduction to Computer Programming Computer programming is the process of creating instructions that tell a computer what to do. It helps people develop applications, websites, and software to solve problems.
  • 2. HTML HTML stands for HyperText Markup Language. It is the standard language used to create the structure and content of a web page.
  • 3. CSS CSS stands for Cascading Style Sheets. It is used to design and improve the appearance of a website by adding colors, fonts, spacing, and layouts.
  • 4. Website Structure A website is organized into different sections such as the header, main content, and footer. A good structure makes a website easier to read and navigate.
  • 5. Headings and Paragraphs Headings are used to organize the content of a webpage, while paragraphs contain detailed information. They help make the page neat and easy to understand.
  • 6. HTML Formatting HTML formatting is used to change the appearance of text. It includes making text bold, italic, underlined, or highlighted for emphasis.
  • 7. Images Images make a website more attractive and informative. In HTML, images are added using the <img> tag.
  • 8. Hyperlinks Hyperlinks connect one webpage to another or open websites on the internet. They are created using the <a> tag in HTML.
  • 9. Tables Tables are used to organize information into rows and columns. They are useful for displaying data clearly and neatly.
  • 10. Properties & Attributes HTML attributes provide additional information about an element, while CSS properties control the design and appearance of elements. Both are important in building a webpage.
  • 11. Elements HTML elements are the building blocks of a webpage. They define the different parts of the page, such as headings, paragraphs, images, and links.
